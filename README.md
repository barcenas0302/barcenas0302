# barcenas0302

Generador de accesos directos para archivos HTML5.

Herramienta web en HTML/CSS/JS puro que crea accesos directos descargables
(`.url`, `.desktop`, `.webloc`) para colocar archivos o sitios HTML5 en el
escritorio.

## Uso

1. Abre `index.html` en tu navegador.
2. Escribe un nombre y la ruta o URL de tu archivo HTML5.
3. Elige tu sistema operativo y descarga el acceso directo.
4. Mueve el archivo descargado a tu carpeta de Escritorio.
