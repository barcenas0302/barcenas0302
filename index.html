Generador de accesos directos HTML5

Crea un acceso directo para tu archivo o sitio HTML5 y colócalo en el escritorio.

Acepta una URL (http/https) o una ruta local a un archivo .html.

Cómo colocarlo en el escritorio

  1. Completa el nombre y la ruta/URL de tu archivo HTML5.
  2. Elige tu sistema operativo y descarga el acceso directo.
  3. Mueve el archivo descargado a tu carpeta Escritorio.
  4. En Linux, haz clic derecho → Permitir lanzar si es necesario.
Funciona 100% en tu navegador — HTML, CSS y JavaScript puro. Nada se envía a ningún servidor.
